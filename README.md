# Deep Dive AI

Deep Dive AI is a beginner-friendly Streamlit prototype for turning lectures and recordings into a timestamped transcript, a basic summary, and possible action items.

## What works today

- Upload audio files (`MP3`, `WAV`, or `M4A`) and video files (`MP4` or `WEBM`).
- Submit a YouTube URL for media that yt-dlp can access and that you are permitted to process.
- Transcribe speech locally with Faster-Whisper, including segment timestamps and detected language.
- Display a simple summary and keyword-matched action items.
- Download the transcript as a text file.

The current summary is **not generated by an AI language model**: it returns up to the first five sentences. Action items are found with a small keyword list, so they may miss tasks or include sentences that are not real tasks. Topic-wise notes, persistent history, and a redesigned dashboard are not implemented yet.

## Requirements

- Windows and Python 3.13 (the current project environment was checked with Python 3.13.15).
- Internet access the first time Faster-Whisper downloads its speech-recognition model.
- The Python dependencies listed in [`requirements.txt`](requirements.txt).

Faster-Whisper uses CTranslate2 and PyAV for inference and media decoding. An external FFmpeg executable is not listed as a Python dependency. The complete audio/video and YouTube workflows have not yet been verified with sample media; some formats or yt-dlp operations may require installing FFmpeg separately.

## Setup on Windows

Open PowerShell in the project folder and run:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If PowerShell says script execution is disabled, use Command Prompt to activate the environment instead:

```bat
.venv\Scripts\activate.bat
```

## Run the app

With the virtual environment active:

```powershell
python -m streamlit run app.py
```

Streamlit prints a local address, usually `http://localhost:8501`, to open in your browser. The first transcription may take longer while the model is downloaded and loaded.

## Run the tests

Run the following command with the virtual environment active:

```powershell
python -m pytest -q
```

### Test Results

The current automated test suite passes all 15 tests.

```text
15 passed in 0.10s
```

The tests cover the current summarizer and action-item helper, plus a small media-filename extension check. That media check is deliberately isolated and is not connected to the Streamlit app yet.

These unit tests do not prove that real audio, video, or YouTube downloads work end to end.

## YouTube and content permissions

Only process content that you own or have permission to use and whose access terms allow it. The app does not try to bypass sign-in, DRM, regional, age, or other access restrictions. If media is inaccessible or yt-dlp reports an error, do not attempt to work around that restriction.

## Current limitations

- The Whisper model runs on the CPU using the `base` model, so processing can be slow on longer recordings.
- The summary is extractive and action detection is heuristic; neither is a substitute for reviewing the transcript.
- Results are not saved to a persistent history.
- End-to-end processing has not been tested with representative media files.
